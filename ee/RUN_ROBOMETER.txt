------------------------------------------------------------------------
 TROUBLESHOOTING
------------------------------------------------------------------------
- vla_server dies with "read failed (status=False)" / "Corrupt JPEG":
    a USB CAMERA is failing -> reseat/swap its cable (port 4.2.4), try another port.
- "[Errno 98] Address already in use" on :8000 or :8010:
    old server still running -> lsof -ti:<port> | xargs kill
- Dashboard shows "unreachable" / no cameras:
    Thor's vla_server isn't up, OR Thor's IP changed -> update --server and relaunch.
- WS and Thor on DIFFERENT subnets (remote WS): use the SSH reverse tunnel instead
    -> see ee/CONNECT_THOR.txt.
- Robometer verdict feels too strict/loose: change --threshold (default 0.5).
- The verdict is Robometer's OPINION (~60% success recognition zero-shot); the runs
    CSV keeps an `outcome` column to correct by hand. Findings: ee/ROBOMETER_VALIDATION.md
