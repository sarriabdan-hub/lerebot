IMPORTANT: SOURCE pos and DEST pos are INDEPENDENT. The DEST is FIXED for the whole session
(it's what the prompt commands); the SOURCE pos CHANGES every episode. It is NOT same-to-same —
e.g. in Session 1 you do LEFT pos 5 -> RIGHT pos 1, LEFT pos 2 -> RIGHT pos 1, etc. That's the
point: the arm must grab the vial WHEREVER it sits and place it WHERE THE PROMPT SAYS.

Each table row = one episode. "src" = which slot to put the vial in (in the SOURCE rack);
"dst" = where you teleop it (in the DEST rack, fixed). Run the matching command from the
COPY-PASTE BLOCK below.

"ds ep" = the global dataset episode index (what the recorder shows as "Recording episode N").

# passed QUOTED inline in each command ("$CAMS") — do NOT fold it into COMMON.
