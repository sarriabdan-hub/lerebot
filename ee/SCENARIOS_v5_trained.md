# vial-sort v5 — trained scenarios & relabeled (POSITION) prompts

**150 episodes (Phase A, runs 1–30).** These are what pi0.5 was actually TRAINED on.

- **Scene / source(`*`) / dest** come from `ee/SORT_SHEET_v5.md`.
- **Trained prompt** is the POSITION-grammar label pulled from the trained dataset
  `./data/vial-sort-v5-ee` (`meta/episodes`), generated by `ee/relabel_positions.py`.
- The sheet's RUN titles are the old COLOR instructions (human recording aid only);
  the model never saw colour — it saw the POSITION prompt below.
- Reading a scene: 6 cols = slots 1..6, left-to-right in the SIDE camera. R/C/G = red/cyan/dark-green.
  `*` = target to grasp. LEFT rack = the one by the bin.
