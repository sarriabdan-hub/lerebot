=========================================================================
 NOTES
=========================================================================
- base_v1 (the 100-episode full-FT checkpoint) was trained on ONE exact sentence:
  "Place the red vial in position 3 of the right rack." It does NOT understand
  paraphrases or other positions — a different string is OUT-OF-DISTRIBUTION and
  degrades the grab. cv_run.py sends this exact sentence by default. Real
  prompt-following (any phrasing, any position N) comes after the varied-label retrain.

- The VLM uses the TOP camera as primary (best for reading the 1x6 grid), with
  the side camera as secondary context. Top-view geometry baked into planner.py:
  arm on the RIGHT; upper row = source/"left" rack; lower row = goal/"right" rack;
  slot numbering position 1 = nearest the arm, position 6 = far boundary.

- To run Qwen ON THOR instead of the workstation (frees the Blackwell for
  training): on Thor run  ollama pull qwen2.5vl:7b , then add this flag to the
  orchestrator in Steps 4/5:   --ollama-url http://192.168.123.198:11434

- If Steps 2/4 hang from the workstation but   curl http://localhost:8000/health
  works ON Thor, it's a network/firewall issue between the two machines — tell me.
