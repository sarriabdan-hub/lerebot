# imgs/

Drop the report's figures here as PNGs, using the exact filenames `main.tex`
expects (see `../imgs_links/figures.md` for the full list and where each one
comes from):

```
system_diagram.png
setup_side.png
cameras.png
teleop_dataset.png
depth_triptych.png
dashboard.png
rack_sort_sequence.png
bin_hover.png
```

Until a file is present, `main.tex` renders a grey placeholder box in its place,
so the document always compiles.
